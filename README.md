# North-American-Flood-Risk-Analogue

This R project expands upon the concept of climate analogues with flood risks to create risk analogues in North America.

Sources to download files used in the analogues:
    Google Drive for large RDS files: https://drive.google.com/drive/folders/1CVUliT-loMANiMJzpowQOYJC7IdmKzdJ?usp=sharing 

American historical temperature, precipitation and elevation data comes from NOAA's GHCN, access here: https://www.ncei.noaa.gov/data/ghcnm/v4/

Canadian historical temperature, and precipitation data comes from ECCC's Datamart, access here: https://dd.weather.gc.ca/observations/xml/
